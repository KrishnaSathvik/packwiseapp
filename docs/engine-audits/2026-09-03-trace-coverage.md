## Reading these numbers

- **95.6% inclusion completeness** (964/1008 engine-generated rows) with
  **zero hard defects** (no row with an empty reason code or an empty signal
  list among engine-generated rows) is a clean bill of health on the
  strictest part of gate 7 — nothing the engine generates loses its causal
  attribution.
- The 44 generic-only rows and 25 quantity-evidence gaps are real, but both
  are *weak-explanation* gaps, not *missing-explanation* gaps — every one of
  those 69 rows still has a reason code, a signal, and prose the user can
  read; they just don't clear the higher "specific" or "always explain your
  number" bar. Both are logged as findings (P2) in
  `docs/engine-audits/2026-09-03-engine-findings.md` rather than treated as
  build-breaking — this mirrors `audit_engine_inputs.py`'s existing
  convention that a tracked, known gap is a reportable finding, not a
  validation failure, so `scripts/audit_recommendation_traces.py` exits 0 by
  default (pass `--strict` for a CI mode that treats the current defect count
  as a regression gate).
